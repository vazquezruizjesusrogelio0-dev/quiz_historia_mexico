**DESCRIPCIÓN**

El proyecto consiste en una serie de preguntas sobre la historia de México, desarrollado en Python. Contiene una interfaz gráfica permitiendo al usuario interactuar 
con el programa ya que es más manejable y fácil de usar.

Las preguntas se almacenan en un archivo CSV y se seleccionan 5 preguntas aleatoriamente para cada partida.

**Características**

-Interfaz gráfica desarrollada con Tkinter.

-Selección aleatoria de 5 preguntas.

-Tres vidas disponibles por partida.

-Sistema de puntuación.

-Cuatro opciones de respuesta por pregunta.

-Registro de aciertos y errores.

-Mensajes para indicar si la respuesta es correcta o incorrecta.

**Tecnologías utilizadas**

-Python.

-Tkinter.

-CSV.

-Random.

**Archivos del proyecto**

**-main.py:** Contiene el código principal del juego y la interfaz gráfica.

**-preguntas.csv:** Almacena las preguntas, respuestas y opciones del cuestionario.

**Instrucciones de ejecución**

**1.** Descargar o clonar el repositorio.

**2.** Tener Python instalado.

**3.** Colocar los archivos del proyecto en la misma carpeta.

**4.** Ejecutar el archivo principal de Python.

**5.** Comenzar a jugar y responder las preguntas.

**Objetivo**

Desarrollar un juego interactivo que permita practicar los conocimientos de historia de México, 
aplicando los conocimientos adquiridos sobre programación, estructuras de control, manejo de archivos e interfaces gráficas en Python.
